# Tramway Entities

## Index page header content placement

See the [main README's Add header content to index pages section](https://github.com/Purple-Magic/tramway#add-header-content-to-index-pages)
for how to define `index_header_content` on a decorator.

The rendered content is placed directly under the page title (and the "Create" button, when present), on its
own row above the search bar and the table — not inline with the title, and not above the table only.
